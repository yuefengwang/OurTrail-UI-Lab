F V2 TYPE

衬线只给活动名。正文 15px；标签 11–12px；数字 tabular；单位小两档；一屏一个主读数。

删除“第 03 期 / 本期头条 / 编辑部”等虚构内容；用“下一场 / 路线索引 / 出发窗口 / 现在要处理”。

F V2 RULES

发现：一张 hero + 3 个事实 + 路线索引行；不做双大图/期号。
详情：路线事实页 + 海拔剖面 + 单一 CTA；不做 6 张白卡/工位编号。
协作：首屏「3 人未签到」；计数带分母；任务优先。
天气：首屏「出发窗口」；路线点/海拔/不确定性；石板蓝只做数据。
