## 0. 一句话

借 AllTrails 的路线事实顺序、Komoot 的路线索引、Spond 的出席摘要、G 的单一读数与 CTA；保留 F 的纸 / 森林 / 陶土色板，删掉期号、工位编号、编辑口吻与重复计数。

## 2. 改了什么

### 发现（`js/styles/F/index.js` L274 / L322 / L349 / L370 / L465；`css/styles/F.css` L1933 起）

- **去编辑化**：删除「第 03 期」「本期头条」「每期由领队与编辑共同挑选」；「工位 01/02」改为普通分区标题。
- **最近出发**：照片上保留日期章，新增纸底状态章「报名中 · 剩 7 位」；主 CTA 也压在照片底边，375 可用 603 内直接可见。日期 / 集合 / 主读数 / 一个 CTA 组成一条决策链；集合点从索引移进头条，避免下架索引里的集合行后丢信息。
- **一个主读数**：`18.6 km` 作为唯一大数字；爬升、余位、人均退为同排事实。
- **路线索引只剩一块纸带**：删除「本月概览」计数条（原与筛选 tab 重复 9/5/2/2），也删除独立的「筛选与搜索」分区；筛选、搜索直接贴着月份行。分区右上角说明「最近出发置顶」，筛选 / 搜索时变成「按出发时间」，无结果时为「无匹配」。
- **行**：日期 / 缩略图 / 标题 / 路线·城市·天数 / 难度·距离·爬升·费用 / 状态·余位；已结束与已取消单独成组，不再混在未来月份里。
- **加载态**：骨架顺序改成与正常页一致（照片 → 标题 → 集合 → 简介 → 读数 → 索引 → 行），不再先出索引块再出照片。

### 详情（`js/styles/F/index.js` L552 / L743 / L783 / L826；`css/styles/F.css` L1143 / L1296）

- **首屏补齐决策事实**：活动名 + 日期 / 时间 + 难度 + 集合地点 + 领队 + 状态 / 余位；概览卡给出距离 / 爬升 / 名额 / 截止 / 费用 / 倒计时。照片底部 scrim 加深，白字不再压在亮石头上。
- **去重**：删除概览卡头重复的「进阶 · 领队 林溪」；删除首字下沉「夜」；删除剖面图下复述 2434 m / 04:50 的长注记，收紧为「示意剖面，非实测轨迹。」
- **装备清单**：两栏 + 装饰性的 01–05 序号改为单栏「名称 + 提醒」；序号不是顺序，删掉后才像准备清单而不是流程。
- **同行人**：报名阶段不再显示「已签到 12」，改为「车辆 4」；签到留到协作页。说明文案从工坊自指的「这里只列领队与车长」改为「完整名单与签到在协作页。」
- **代价**：详情整页 390 宽从 3,151 px 到 3,276 px（+4.0%），主要来自装备单栏化；换来的是一眼能读的检查清单。

### 协作（`js/styles/F/index.js` L903 / L1015 / L1228 / L1251；`css/styles/F.css` L1534 / L1610 起）

- **任务前置**：把「下一步」从页面末尾移到页头之后。首屏先看到原因与唯一主操作「发起出发确认」，现场计数与名单/分车随后。
- **任务实时推导**：文案由名单算出来（未到人数、未排车人数），签到与「一键全到」后立即更新；发起后 meta 变「已发起」、按钮变「确认已发起」。
- **去重复集合信息**：页头只保留一次「集合中 · 22:10 出发 · 茶店子客运站 · 地铁 A 口」；删除现场计数里重复的集合点/出发时间块，也删除名单总览里的集合点/集合时间规格行。
- **删掉与现场矛盾的倒计时**：原「距出发集合 1天00时」与现场签到 21:32–22:03 的「集合中」状态冲突；改为「到点人数 12 / 15」一条进度条。
- **台账去噪**：名单 tab 删除自指的「口径」注记；分车 tab 的空位说明改为按车辆实时推导（2 号车、3 号车、4 号车仍有空位；待定成员 1 人），并删除「点成员行可在名单里调整」这句未实现的承诺。
- **字级**：「3 人未签到」从衬线刊头改为 30px 无衬线状态句；分区不再带「工位 01–03」编号。
- **页脚**：协作没有照片，删除假的 Unsplash 署名，改为「演示数据 · 固定名单与签到快照」。
- **高度**：内容高 **2,468 → 2,013 px（−18.4%）**；交互实测：一键全到 → 到点 15/15、任务句更新；发起出发确认 → 已发起；四个 tab 切换无 pageerror。

### 天气（`js/styles/F/index.js` L1400 起；`css/styles/F.css` L1609 起）

- 去「工位 01–05」编号；「周日清晨云海机会中等」从衬线刊头改为无衬线 30px 判断句。
- 首屏保留出发窗口、站点海拔、48h 温度/风/云量/降水与距窗口倒计时；曲线、逐时判定、窗口判定、决策建议的结构未重写。
- 两条交互注记收短为「点一行定位到该小时。」「点一行定位到该时段。」；页脚删除假 Unsplash 署名，改为「演示数据 · 静态气象快照」。
- **高度**：内容高 **2,085 → 2,063 px（−1.1%）**；曲线/表格与数值未改。

### 字 / 色（`css/styles/F.css` 顶部 token；L1933 起）

- 纸面 `#F6F3EC`、纸卡 `#FCFAF4`、燕麦 `#E8E3D7`、森林 `#1E3D32`、动作深绿 `#173A2F`、陶土 `#A4562F`、信息蓝灰 `#4F6871`。
- 衬线只给活动名 / 详情主标题；刊头、分区、行标题、按钮全部无衬线；正文 14–15px，辅助 11–12px，数字 tabular。
- 陶土只留给警示与终态（名额紧张、取消、待安排车辆、降雨），CTA 与可报名状态用深绿。

## 4. 还差什么（如实）

1. **375 首屏**：发现页主 CTA 已在照片底边（y=413–457），375 可用 603 内可见；状态章、日期、主读数也在折线内。详情页加了 375 专用短头图（244 → 200px），费用已进入首屏；倒计时仍在底栏下（y=602 起，底栏 598 起），需要一次短滚动。390 / 414 完整可见。
2. **角色与权限未接**：协作页仍是领队视角，没有 staff / 车长 / 成员分支或权限门；发起出发确认、自动排座仍是演示 toast。角色与命令在生产仓库已有，但 F 实验室没有接。
3. **真实地图 / 气象 API 未接**：详情用照片 + 海拔剖面，天气用固定 48h 数据；生产已有的真实地图与气象入口未迁移。
4. **生产迁移未开始**：没有改 `D:\OurTrail`，没有接真实命令、报名状态或天气 API；本页仍是固定演示数据（演示日为 2025-10-17），页面底部保留实验室声明。
5. 参考板是结构示意，不含第三方品牌资产；F 的陶土 / 森林色板、纸质分区和测量数据是 F 自己的。
