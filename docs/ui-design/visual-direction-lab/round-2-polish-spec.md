# 第二轮打磨规格（Round 2 Polish Spec）

> 背景：用户评审第一轮五风格后的反馈（原话见 §0）。本轮目标：**在不改变每种风格定位与已受认可特质的前提下，全面雕琢完成度**——信息展示、视觉工艺、交互反馈三条线一起收口。
> 执行方式：每风格一个独立 Agent，只允许修改本风格自有文件；本文档为统一基准与验收口径。

---

## 0. 用户反馈原文（改进方向与红线依据）

| 风格 | 反馈原话 | 解读 |
|---|---|---|
| A 山野编辑部 | 「风格上我比较喜欢。但是信息展示、交互上还需雕琢。」 | 保留刊物气质；重点打磨信息扫读与交互反馈 |
| B 瑞士功能主义 | 「信息密度、排版我比较喜欢，但视觉效果确实糟糕。」 | 保留网格/密度/排印纪律；重点重建视觉表现力 |
| C 静野 | 「问题跟山野编辑部类似。」 | 保留平静气质；同 A 的打磨方向 |
| D 野外仪表 | 「在信息密度上很好，但跟瑞士功能主义问题一致，视觉效果还需雕琢。」 | 保留密度与仪器感；重点提升工艺精致度 |
| E 远征现代 | 「信息展示组织可能是最好的，但是 UI 不行。」 | 信息组织/编号系统不动；重点重做组件工艺与一致性 |
| 统一 | 「完成度不够高，还需要仔细再优化雕琢。」 | 逐屏收口：状态、微元素、动画、对齐、边界情形 |

## 1. 总原则（所有风格适用）

1. **保定位**：A 继续刊物编辑、B 继续瑞士网格、C 继续低刺激、D 继续仪表、E 继续海报——只雕琢不换向。
2. **只动自有文件**：
   - 允许：`css/styles/<X>.css`、`js/styles/<X>/index.js`、本风格截图（`screenshots/<X>-*.png`）。
   - 禁止：`css/tokens.css`、`css/base.css`、`css/components.css`、`js/app.js`、`js/data.js`、`js/render-common.js`、`index.html`、`compare.html`、`tools/*`、`docs/*`、其他风格的任何文件。共享文件确实需要改动的，**在报告中提出**，不要动手。
3. **数据零改动**：`js/data.js` 不动；不新增/删除内容；只改进既有数据的展示。
4. **保持接口钩子不变**：`[data-testid="primary-cta"]`（详情页主按钮）、`window.__LAB_READY__`、`?state=empty|error|disabled` 行为、`bare=1` 渲染。
5. **不加依赖、不加字体、不发网络请求**；纯原生 CSS/JS。
6. **不留半成品**：每个打磨项必须在 四页面 + 状态页（空/错/禁）+ 按钮反馈 上一致生效，且不破坏 375/390/414 三档。

## 2. 跨风格完成度清单（十项，逐套自查）

1. **数字排版**：所有数据数字 `font-variant-numeric: tabular-nums`；单位小一号；列内对齐。
2. **交互反馈完备**：所有可点击元素有 `:active` 按压反馈 + `:focus-visible`；箭头/chevron 按压位移；按钮「默认→加载→终态」链保持且更顺滑。
3. **过渡动画**：统一缓动与时长（各风格自定基调，150–250ms 档）；toast 出入场；标签指示条滑动；图片加载淡入；加 `@media (prefers-reduced-motion: reduce)` 关闭动效。
4. **间距节奏**：按本风格 token 自查每个区块纵向间距，修掉孤例（过大/过小的 padding、margin）。
5. **线系统**：边框/分隔线颜色、细度、缩进一致；避免相邻双线；组层级分明。
6. **长内容稳健**：最长标题不溢出、不孤字；sticky 不遮正文（底部留足 padding）。
7. **微元素**：徽标/标签/计数/日期块光学对齐；箭头/圆点风格统一。
8. **状态四态**：空/错/禁用三种 collab 状态截图重拍并核对，与新打磨一致。
9. **图片**：裁切比例统一、不变形、有淡入；叠字处 scrim 可读。
10. **零控制台报错**；三档视口不破版。

## 3. 各风格打磨清单

### A 山野编辑部 — 信息展示 & 交互雕琢
信息展示：
- 筛选标签：加小号计数（全部 9 / 可报名 5 / 已成行 2 / 已结束 2）；选中墨条指示。
- 发现列表：每项「日期 + 状态 + 剩 N 席」做成右对齐可扫读元信息（tabular）；按时间分组加小眉标（如「十 月」分隔）；缩略图比例统一。
- 详情：事实网格对齐 + tabular；行程节点按日分组更清晰（10/18 夜段 / 10/19 段）；成员行对齐精修。
- 协作：顶部统计行（成员/已通过/已签到/待审核/候补/待安排车辆）列对齐与分隔精修；「到点 12/15」配细发丝进度暗示。
- 天气：表格数字列对齐；窗口提示卡与脚注（演示数据）精修。
交互：
- 筛选切换：指示条滑动动画 + 内容淡入；按压态。
- 搜索框 focus 态（墨线加深）。
- 列表项/链接按压态；箭头按压位移。
- 报名按钮链（加载→已报名·待审核）动画更顺滑；toast 出入场动画。
- 图片淡入。
红线：刊物排印气质、纸面配色、留白节奏不变。

### B 瑞士功能主义 — 视觉雕琢（密度/排印不动）
现状病灶：全站无照片、无强调色，像「排印样张」而非产品。
核心手段（按序）：
1. **引入唯一信号色**（信号红 `#D2382C` 或国际橙任选其一，全局纪律化）：面积 ≤5%——选中标签墨条与计数、当前/窗口行标记、主按钮、关键状态点。
2. **摄影系统**：现有 9 张照片瑞士化处理——黑白（grayscale+微对比）+ 硬裁切：发现页头条整幅黑白大图、详情 hero 黑白图、索引列表 48–56px 方形黑白缩略图；图注微号大写。
3. **规则系统**：粗细两级线（章节 2px 黑线 vs 1px 发丝）；页头海报化（display 加大、字距更紧）；表格日分隔加粗。
4. **表格精修**：行高节奏、数字右对齐 tabular、表头微号大写、窗口/当前行信号色标记（左色条或底线）、按压反馈。
5. **天气矩阵**：窗口小时行信号色强调；「现在」标记精修；日分隔规则化。
6. **微元素**：箭头/序号/日期块对齐；按钮直角 + 按压态；focus-visible。
红线：零圆角零阴影保持；灰度主导保持；信息密度不降。

### C 静野 — 信息展示 & 交互雕琢
信息展示：
- 筛选 chip 行精修（尺寸、内边距、选中对比、计数融入如「可报名 5」）；与「共 9 项 · 可报名 5 项」行去重/分工。
- 列表行：缩略图统一尺寸与圆角；行内三级信息（标题/事实/状态）对比稍微拉开；「剩 9」tabular。
- 天气：温度曲线标注精修；daySentence 强调级别；统计格对齐。
- 协作：进度条精修（更细、圆头、入场动画）；成员行状态点语义色纪律。
交互：
- 按压态（柔和 200–250ms）；chip 选中过渡；搜索 focus；sticky dock 滚动后分隔态；toast 与按钮链。
红线：低刺激基调不破坏（对比提升只限必要处）。

### D 野外仪表 — 视觉雕琢（密度不动）
现状病灶：多色小顶线瓷砖、图表噪声、满屏边框盒子——「调试面板感」。
核心手段：
1. **层级**：每屏一个「主读数」（字号加大 + 单位小号）；统计格统一强调规则（替换 4 种随机色为统一系统）。
2. **图表**：折线/柱/带宽/标注全面精修——更少更浅网格、统一线宽、虚线/帽端规范、注释引线专业化、「第 33/48 列」转为仪器标注语言而非调试文案。
3. **面板系统**：统一面板头（标签 + rule + 右侧 meta）；内边距标准；减少纯边框，用微底色分层表达层级。
4. **刻度元素**（到点刻度条 0–100%）精修为可信仪器。
5. **功能色小词典**（温/水/风/云）风格内统一；品牌绿用于主数据。
6. 表格/按钮/标签按压态精修。
红线：信息密度不降；仪器感保留但更「精工」。

### E 远征现代 — UI 雕琢（信息组织不动）
现状病灶：海报头强，但组件混淆——通用白色圆胶囊 chip、全圆搜索框、tile 黄线重复、sticky 过高、对齐欠精。
核心手段：
1. **形状系统统一**：定一套半径纪律（海报方块为主；chip 改为直角块、选中深色；搜索 6–8px；标签直角）并全程一致。
2. **chip 行重做**：融入海报语言（直角、选中深色块、黄色计数），不再用默认胶囊。
3. **tile 2×2 精修**：数字+单位排版、黄线 inset 统一或换更高级的强调符。
4. **sticky CTA 区重排**：层次收紧、内边距对齐、按压态；保留步骤标签与信息行。
5. **深色表面工艺**：分层（底/升）、1px 微光描边、图片 scrim 统一；长页明暗节奏。
6. **列表项**：缩略图 crop/圆角统一、「01」徽标对齐、右标签与 chevron 对齐。
7. **对齐大扫除**：24 网格、meta 行基线、分隔尺寸。
红线：信息组织与编号系统（R-018 / 01 / 05 等）不动。

## 4. 验收与交付要求

每个风格 Agent 完成后必须：
1. `node --check` 过一遍所有改动的 JS（注意用临时副本方式，见任务书）。
2. 重拍本风格全矩阵 + 状态组图（命令与端口见各任务书）。
3. 读图自查：至少 4 页 fold + 2 页 full + 2 张状态，对照本文清单逐项核对；发现问题就地迭代（至少一轮）。
4. 报告格式：改动文件 / 每页改动摘要 / 交互改动 / 证据截图清单 / 未完成项与原因 / 共享文件诉求。
