# 视觉评审 — 标准、证据与结果

> 依据任务 §5。评审对象是**可运行原型**（非静态稿）：五风格 × 四页面 × 三视口全矩阵截图 120 张 + 交互状态 20 张 + 同页对照表 5 张，全部逐张复核；评审后修复的问题均重截复验。（Round-2 修订与第六风格 F 终评见 §9–§10。）
> 证据目录：`prototype/screenshots/`（文件命名规则见 README §4）。主评审视口 390×844；375/414 为整页抽检。

## 1. 评审基准（任务 §5.1）

| 维度 | 权重 | 判据摘要 |
|---|---|---|
| 真实产品感，是否摆脱 Demo 化 | 25% | 是否像真实可用的户外产品而非概念稿/模板站 |
| 信息层级与可读性 | 20% | 主次清晰、扫读成本、长内容节奏 |
| 户外品牌辨识度 | 20% | 气质是否鲜明、是否落入套路（山峰图标/绿渐变） |
| 视觉完成度与一致性 | 15% | 跨页面/跨状态/跨视口的一致与细节完成 |
| 小程序适配与操作体验 | 10% | 视口适配、触控/操作可达、交互反馈 |
| 组件复用和长期维护性 | 10% | 令牌纪律、样式复杂度、迁移与复用成本 |

评分 1–5（0.5 步进）+ 具体证据与扣分原因；总分为权重加权（百分制）。

## 3. 各风格评语（含证据与扣分原因）

### A 山野编辑部 — 87.0（总评分第一）

- **产品感 4.5**：刊物式节奏（眉题 → 大标题 → 导语 → 事实行）没有任何 demo 痕迹；`A-detail-390-full.png` 中「夜」字头 + 事实行（18.6 km / ↑1,180 m / 17/24）的编辑感在全套中最强。扣分：信息密度中低，工具场景偏散。
- **层级 4.5**：kicker/display/lede/fact-row 四级清晰，长页（~2811px）节奏不塌。
- **品牌 4.5**：纸白 + 森林绿 + 陶土强调的组合辨识度高且不老套（无山峰图标、无绿渐变）。
- **完成度 4.5**：四页 × 三视口 × 四态全过；协作「3 人未签到」状态句与按钮反馈完整（`A-collab-*-390-fold.png` 系列）。
- **适配 4.0**：375/390/414 稳定，触控 44/48；扣分：协作页密度低于 B/D，同屏信息量有限。
- **维护 3.5**：图片管线（散列 + 回退 + 脚注）与排版纪律执行成本最高；扣分最多的一项。

### C 静野 — 86.0

- **产品感 4.5**：低刺激、均匀节奏，「雾里的山径」气质成立；空错态（砖玫瑰文字而非红块）尤其成熟。
- **层级 4.0**：层级靠字重与色调过渡，成立但偏柔；强光下的可读性有理论风险（未真机验证，见 §7）。
- **品牌 4.0**：苔绿/雾灰系在户外产品中少见，温和辨识；但不如 A/E 锐利。
- **完成度 4.5**：修复 daySentence 与筛选计数后全绿；天气页散文简报 + 细线曲线完整（`C-weather-390-full.png`）。
- **适配 4.5**：触控 48 最大，节奏舒适，长文阅读体验最好。
- **维护 4.5**：体系简单（色带 + 文字 + 圆点），图片降饱和需生产侧预处理（已列迁移任务）。

### B 瑞士功能主义 — 84.5

- **产品感 4.0**：工程文件般的精确感真实可信；但冷硬感在中段（名单/表格）偏向「后台工具」，缺少户外温度。
- **层级 5.0**：网格、对齐、表格化扫描为全套最高；数字右对齐 + 单位常显（`B-weather-390-full.png` 预报矩阵、`B-detail-390-full.png` 规格表）。
- **品牌 3.0**：按设计「品牌感来自排版本体」，无户外色彩语言——这是明确取舍，也是最低分维度。
- **完成度 4.5**：零圆角零阴影全站一致，几乎无判例外元素。
- **适配 4.5**：行高 44–56、密度最高但可读；小屏最省空间。
- **维护 5.0**：纯规则无魔法值，复用与维护成本最低；组件化潜力最大。

### D 野外仪表 — 83.0

- **产品感 4.5**：工具可信度最强——剖面图、窗口表、单位常显、`YOU` 锚点、倒计时条，像真正的山地工具（`D-weather-390-full.png`）。
- **层级 4.5**：标签-值-单位体系使任意数据可快速判读；委托 05 节点登顶标注与 04:50 登顶时刻交叉一致。
- **品牌 3.5**：技术语言锋利但窄，不适合覆盖全部用户场景（发现页情绪价值弱）。
- **完成度 4.5**：数据勾稽全部通过（52+6=58、12/15、第 33/48 列等）。
- **适配 4.0**：13.5px 正文为全套最小，紧凑在 375 下需实机复核（已抽检通过）。
- **维护 3.5**：图表/剖面/仪表元素最重，迁移工作量与回归面最大。

### E 远征现代 — 82.5

- **产品感 4.0**：海报感强、行动力足；深色块与编号系统（R-018）完成度高。扣分：个别页面深色块占比大，长滚偏沉。
- **层级 4.0**：大数字 + 色块分区，首屏冲击力最强；长页章节感靠编号维持，中段略程式化。
- **品牌 4.5**：辨识度全套最高；远征黄小面积使用纪律良好（无黑底橙子套路）。
- **完成度 4.5**：修复默认日与文案重复后全绿；禁用态锁定提示（签到已锁）表达清晰。
- **适配 3.5**：深色块在长页重复出现时视觉重量最大；日常轻户外需降级版本（原型已试一个浅色分支，完整降级未做）。
- **维护 4.0**：编号/色块体系成规律，但自定义样式量大。

## 7. 尚未验证的场景（**不得记为通过**）

1. **微信真机/开发者工具渲染**：本评审基于 Web 原型；WXSS 容器、字体度量、安全区、手势差异未验证（迁移各批必须真机验收，见迁移方案 §4）。
2. **小屏（≤375px 整页逐张评审）**：375 视口已截图并抽检通过，但未逐张评审；更窄机型与分屏未覆盖。
3. **真实后端数据**：原型为固定演示数据（明示）；接口联调未涉及。
4. **动效细节**：motion 令牌仅定义并静态验证，动画曲线/时长未逐帧核验。
5. **横屏/平板**：未覆盖（生产端存在 weather-chart 横屏页，原型未做）。
6. **低对比风险（C）与强光可读性**：未做真机强光环境对比度核验；WCAG 逐项审计未做。
7. **图片素材依赖**：A/E 的成品质感部分依赖摄影素材；生产真图需 schema 变更（ADR）。

## 8. 推荐主风格及证据（任务 §5.4）

**首选：A 山野编辑部（87.0）为首批主品牌方向；C 静野（86.0）为等位备选。**

选择依据（全部来自本评审证据）：

1. **总分第一**，且产品感/层级/品牌/完成度四项 ≥4.5——「高级、克制、有辨识度」的产品期望命中面最大。
2. **迁移距离最近**：现行生产已是编辑式方向（app.wxss 已有 `.display/.lede/.kicker/.fact-row/.hero-cover` 类族），A 是同一族语言更彻底的推进，P0 令牌迁移即可承接；C 为中等距离（整体转调）。
3. **高曝光页面（发现/详情）吸引力最强**：`compare-discover-390.png` 横向对照中 A 的刊物式列表在品牌表达与浏览欲望上明显占优。
4. **协作/工具场景短板可用 B/D 的纪律补齐**（组合策略，非全盘替换）：
   - 信息组织原则借用 **B**：数字右对齐、单位常显、表格化扫描（用于协作/名单/表单页）；
   - 专业数据表达借用 **D**：剖面/窗口表/单位/锚点（用于天气/路线页）。
5. **E 保留为对比方向**：验证「行动感」是否需要更强的竞价——若用户研究显示转化更依赖行动感，可再评估 E 的局部入口语言。
6. **C 的使用场景**：若评审最终更看重温和、阅读与低素材依赖，C 可直接转正为备选主方向（与 A 差距 1 分，在评审误差带内）。

**冻结前建议的最后一步**：在真机上以 A/C 两套做同内容最终对比（真机 WXSS 渲染），再冻结主风格——这一步属于迁移方案第 0 批的前置任务。（**F 轮更新**：对比对象升级为 **A／F**，见 §10.2。）
