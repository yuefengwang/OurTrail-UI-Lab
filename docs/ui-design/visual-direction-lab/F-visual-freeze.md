## 1. 参考图分析：共同语言与不借用的部分

8 张参考图的共同点，不是某一个产品的组件，而是五条稳定的审美规则：

| 共同语言 | 参考图里的表现 | F 的采纳 |
|---|---|---|
| 深森林绿 + 暖石色 | 深绿承担品牌 / 主操作；暖白、石色做阅读地面；低饱和苔色辅助 | 森林绿 / 动作绿 / 纸面 / 燕麦 / 陶土保留；不用荧光、渐变 |
| 真实户外摄影 | 满幅自然光地貌，白字压暗部；统一裁切 | 16:10 hero、日期 / 状态压图、固定 scrim；不摆拍、不 HDR |
| 编辑字 + 数据字 | 地点 / 活动名用衬线；UI 无衬线；一个大读数 + 等宽数字 | 30 serif 活动名、30 无衬线刊头、18.6 km 主读数 |
| 细线 + 克制圆角 | 发丝线、留白、少量圆角；不是每块内容都装卡 | 1px 线、2px 图片 / 4px 按钮、纸带分区 |
| 地图 / 剖面 / 状态是工具 | 路线、海拔、天气、状态词都服务判断 | 路线示意、海拔剖面、48h 曲线、逐时 / 窗口表；真实地图仍由生产 route snapshot 提供 |

**明确不借**：整屏深色仪表盘、圆角卡片墙、onboarding / 社区 feed、导航地图外壳、橙色主 CTA、品牌 logo 与素材。F 的路线图只做“节点示意 · 非导航”，不伪造坐标。

其中两张补充参考图（AllTrails 类探索页、Diamond Lake 详情页）被本轮再次点名：据此补入 **路线示意 + 剖面、详情返回、顶部搜索**；卡墙、邀请横幅、底部导航和地图导航壳不复制。补入细节见 §3.4。它们属于参考产品的业务与外壳；OurTrail 是私群活动协作工具，不是导航或社区产品。

**是否新建第 8 套 App 风格：不新建。** 参考图的共同审美已经能被 F 吸收；剩下的差异是产品外壳（深色大块、圆角卡墙、导航地图）。新建一套 App 风格会重启探索、制造第二基线，也违背“本轮完成视觉定稿”的目标。新建的是独立的**视觉规范页**（`style-f-final-spec.html`），与 7 套 App 风格分开，不参与风格竞争。

## 3. 本轮修改摘要

以参考图补入的三处产品化细节（路线示意 / 详情返回 / 顶部搜索）和两类可用性修正（对比度 / 触控）为主；不换风格、不重排业务信息、不改状态机。

### 3.1 对比度

| Token | 改前 | 改后 | 纸面 / 纸卡 / 燕麦 |
|---|---|---|---|
| 三级文字 `--lab-text-3` | `#828A7D` | `#5D685C` | 5.26 / 5.59 / **4.56:1** |
| 二级文字 `--lab-text-2` | `#58645A` | `#4C584E` | 6.74 / 7.15 / 5.83:1 |

原三级文字在燕麦底只有 **2.79:1**，11–12px 的 meta、时间、单位不达标。本轮全部达到 AA 正常文本；状态色（成功 / 陶土 / 危险 / 信息）保持原有的文字 + 方点双通道，不靠颜色单独区分。

### 3.2 触控

- 发现筛选 Tab：32 → **44px**，最小宽度也补到 44。
- 搜索框与“清空”：24 / 19 → **44px**。

## 4. 最终视觉原则

1. **Natural, not rough**：纸面、森林、陶土与真实摄影；不用仿旧、印章、露营装饰。
2. **Refined**：层级来自字号、字重、行距、留白和发丝线，不来自满屏卡片和渐变色块。
3. **Editorial**：衬线只给活动名 / 详情主标题；刊头、分区、行标题、按钮全部无衬线。
4. **Functional**：发现回答“最近去哪”；详情回答“适不适合、怎么集合”；协作回答“现在做什么”；天气回答“哪个窗口能走”。
5. **Trustworthy**：一个主读数；状态 = 词 + 方点 + 位置；数据标注口径；路线示意不冒充导航地图，不伪造坐标与天气。

规则：陶土只做警示与待办；动作绿只做主操作；深色块只给 CTA 和图片日期章 / 状态字；不用渐变做层级，渐变只给照片 scrim。

### 5.2 字体

| 角色 | 值 | 用法 |
|---|---|---|
| 刊头 / 协作状态 / 天气判断 | 30px / 750 / 1.18 / -0.5 | 无衬线 |
| 活动名 / 详情主标题 | 30px / 700 / 1.25 / -0.3 | 衬线；只给活动名 |
| 分区 / 路线名 | 17px / 650 / 1.4 / -0.1 | 无衬线 |
| 正文 | 15px / 400 / 1.6 | 活动说明、表格值 |
| 辅助 | 12px / 400 / 1.5 | 单位、集合、元信息 |
| Kicker | 11px / 600 / 1.4 | 眉题、标签、表头 |
| 主读数 | 30px / 750 | 18.6 km、倒计时 |
| 台账读数 | 18px / 700 | 规格行、计数 |

数字统一 tabular；单位比数字小两档；英文只做产品词汇，不做装饰。

### 5.3 间距 / 几何 / 图片

- 页边距 20px；分区节奏 24px；触控 44px；主 CTA 48px。
- 图片圆角 2px；按钮 4px；纸卡 / chip 2px；不使用大阴影（toast 除外）。
- Hero 390 宽 244px 高（16:10）；375 详情短屏 200px；缩略图 64×48（4:3）；照片 credit 11px。
- 图标线性 1.5px stroke / 18px；状态方点 5px。

### 5.4 组件

- **Section**：满幅纸带 + 发丝线 + 17px 标题；右上 11px meta；不使用圆角卡。
- **Hero**：满幅照片 + 日期章 + 状态章 + 底部 scrim；活动名衬线；主 CTA 唯一。
- **Readout**：一行 4 格；只有一个 lead 大数字；其余标签 / 单位退位。
- **Index row**：日期 / 64×48 缩略图 / 标题 / 路线·城市 / 难度·距离·爬升·费用 / 状态·余位。
- **Task**：`下一步` 分区在最前；一句原因 + 唯一主 CTA；状态变化用文字，不用新色块。
- **Table**：发丝线行、数字右对齐、行高 44px；图例 / 单位 / 选中态同一数据源。
- **Route map**：等高线 + 路线 + 节点 + 起点 / 登顶 / 终点；图例 11px；必须标注「非导航」；不接假坐标。
- **State**：空 / 错 / 禁用统一使用 state block；禁用只用透明度与文案，不新造红色块。

## 11. 正式产品迁移建议

1. **视觉**：把 F 的颜色 / 字级 / 间距 / 圆角 / 图片比例映射进正式小程序的 `app.wxss` 与设计 token；不要复制 lab 的 DOM、lab store 或演示数据。
2. **行为**：用 `prototype/final/` 的角色、报名状态、审核、分车、签到、天气入口和测试作为行为参考；生产命令以 `D:\OurTrail` 为准。
3. **地图 / 天气**：F 的路线示意是“节点图 · 非导航”，不是地理地图；生产已有真实 route snapshot 与气象入口，迁移时用真实地图替换示意，不在 lab 伪造坐标；天气图迁移时把逐小时热区改为可拖拽 scrubber。
4. **组件顺序**：先迁移 token / 字级 / 按钮 / 状态词，再迁移四页模板；发现页的“照片 CTA + 路线索引”、详情页的“概览 + 剖面 + 装备清单”、协作页的“任务前置”、天气页的“窗口在前”是四条结构规则。
5. **验收**：以本文件的 375 / 390 / 414、对比度、触控、0 溢出和状态截图作为回归基线；生产上线前再补真实数据、权限和 API 测试。
